## English

Per-app hook isolation: override the kernel and framework hook mask for an individual app instead of only the global protection level, via a new settings icon on each app card in the tunnels list.

## Русский

Изоляция хуков по приложению: переопределение маски хуков ядра и фреймворка для отдельного приложения вместо только глобального уровня защиты — через новую иконку настроек на карточке приложения в списке туннелей.
